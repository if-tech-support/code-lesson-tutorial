# code-lesson-tutorial
コードレッスンのチュートリアルで使用するWebアプリ・サイトを管理するリポジトリです。

---

## Sassのセットアップ・起動方法

### 1. 依存パッケージのインストール（初回のみ）

```bash
npm install
```
- プロジェクトのルートディレクトリで実行してください。

### 2. Sassの監視・自動コンパイルの開始

```bash
npm run sass
```
- **作業を始める前に必ずこのコマンドを実行してください。**
- これで、すべての`*.scss`ファイルが同じ階層に`*.css`として自動コンパイルされます。

---

## Sassコンパイル運用ルール

1. **同階層出力**
    - 各ディレクトリ内の`*.scss`ファイルをコンパイルした際、必ず同じフォルダー内（同階層）に`*.css`ファイルを出力します。
2. **編集したファイルのみコンパイル**
    - 編集した`*.scss`ファイルのみが自動でコンパイルされ、他のディレクトリのscssには影響しません。
3. **出力ファイルの種類**
    - 出力されるのは`style.css`と`style.css.map`（ソースマップ、必要な場合のみ）だけです。
    - minファイル（例：`style.min.css`）は出力されません。
4. **Live Sass Compilerの無効化**
    - VS Code拡張「Live Sass Compiler」は、このプロジェクト内では自動的に無効化されます。
    - `.vscode/settings.json`により、すべての`*.scss`ファイルがLive Sass Compilerの監視対象外となっています。
    - 誤ってLive Sass Compilerを動かしても、このプロジェクト内ではcssやmin.cssは生成されません。

---

### 注意
- 新しいディレクトリやscssファイルを追加しても、上記手順で自動的に監視・コンパイルされます。
- bash以外のシェル（zsh等）をお使いの場合は、別途ご相談ください。
